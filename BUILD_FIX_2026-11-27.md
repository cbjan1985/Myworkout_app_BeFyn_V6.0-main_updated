# FiT85 V6.5 build-pipeline correction — 27 November 2026

## Root cause
The security regression test attempted to simulate a workflow without explicit Bash pipefail protection by removing `shell: bash` with a regex that only matched a bare line. The current FiT85 workflow declares `defaults.run.shell: bash` with an inline explanatory comment. The regex did not remove that declaration, so the scanner correctly found pipefail protection and the test incorrectly expected `CI-PIPEFAIL`.

## Correction
Updated `tests/security-scan.test.js` to remove every `shell: bash` declaration, including declarations with inline comments, from the temporary vulnerable workflow:

`/^[ \\t]*shell:\\s*bash\\b.*$/gm`

The production scanner and workflow protections were not weakened or removed. The test continues to verify that the scanner flags a workflow after all explicit pipefail protections have been removed.
