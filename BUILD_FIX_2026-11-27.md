# Build pipeline fix — 27 November 2026

## Root cause
The latest GitHub Actions log stopped during the security-scanner test suite, before either Android/Gradle build step ran. The failing test was `the scanner catches seeded vulnerabilities`, with the assertion `missing detection: CI-PIPEFAIL`.

The workflow already configures `defaults.run.shell: bash`, which makes GitHub Actions invoke Bash with `-e -o pipefail`. The scanner's CI-PIPEFAIL check was too broad: it treated any `shell: bash` or pipefail-like text as sufficient and did not reliably distinguish the actual YAML shell configuration from comments/unrelated script text. The seeded regression test removes the explicit shell configuration and expects the scanner to detect that regression.

## Change
Updated `tools/security-scan.mjs` to check for an explicit workflow/job default `shell: bash`, a step-level `shell: bash`, or an explicit `set -euo pipefail` line. The scanner no longer relies on unrelated text or comments.
