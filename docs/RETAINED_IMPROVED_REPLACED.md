# V5.0 capabilities: retained, improved, replaced, consolidated, removed

| V5.0 capability | V6.0 | Notes |
|---|---|---|
| 8-week programme (hard-coded) | **Replaced** by versioned template + instance + cursor | Same exercises, same order, same data; imported 1:1 |
| Per-set history log | **Retained** and **improved** | Grouped into session logs; append-only; corrections are audited |
| Per-date overrides, saved plans, yoga and cardio sessions | **Consolidated** into Train > Workouts | Nothing dropped; items without an exercise list are kept view-only |
| Move/swap workouts inside a week | **Improved** | Preview, conflict checks, undo, change log |
| Workout Library (custom exercises, hide/restore, YouTube links) | **Consolidated** into the Exercise Master | Custom exercises merged; hidden items become archived and can be restored; links kept (web links only) |
| GIF/video folder and local media | **Retained** | Same native folder picker; media saved by V5.0 still shown |
| Per-side rep splitting | **Retained** | Left then Right steps |
| Rest timer, transitions | **Improved** | Next-up preview, +15 s, voice countdown |
| Breathing guidance with voice | **Retained** | Uses the phone's text-to-speech via the existing plugin |
| Excel weekly schedule template | **Retained** | Excel import and export of programmes |
| Local workout history dashboard | **Improved** | Progress tab |
| Protected health tracker (password vault) | **Replaced** | Body measurements in FiT85; V5.0 encrypted records import with your own password; no default password |
| Google Fit / Fastrack | **Replaced** | Health Connect (read-only) is the supported path on Android |
| Black theme | **Replaced** | System/light/dark themes from the design system |
| Auto backup to a fixed file | **Replaced** | Explicit backup/restore (and a safety snapshot before every restore) |
| App icon (X mark) | **Replaced** | New FiT85 mark (replaceable via `tools/make-icons.mjs`) |
| "Redo" in workouts | **Removed** | Back (undo last set) is provided; redo was rarely useful |
| PDF user manual | Deferred | As agreed |
