## What the new pipeline does (`.github/workflows/build-apk.yml`, `tools/android-build.sh`, `tools/verify-apk.sh`)
1. `shell: bash` for every step (`bash -eo pipefail`).
2. `npm install`, then `npm test`, `node tools/check.mjs` (contrast, syntax, import graph), `node tools/security-scan.mjs`, an `npm audit` gate for high/critical advisories.
3. Signing identity step: uses the repository secret `BEFYN_V5_KEYSTORE_BASE64` if present, else the committed V5 keystore; **fails if the certificate fingerprint is not the V5.0 one** (`signing/V5_CERT_SHA256.txt`).
4. Copies the SheetJS library into the web app. There is no bundler: the "production frontend" is the `www/` folder, and the script verifies its required files exist.
5. `tools/android-build.sh`: `cap add android`, verifies `gradlew` and the Gradle files exist, patches version/Kotlin/Health Connect/manifest/launch screen, `cap sync`, **verifies the web app and seed data arrived in `android/app/src/main/assets/public`**, installs icons and the signing key, then runs `./gradlew :app:assembleDebug --stacktrace --no-daemon` with `pipefail`.
6. If that fails: key error lines go to the run summary, and a second build **without Health Connect** runs (named `BeFyn_V6.5_no-health.apk`, so you can tell).
7. `tools/verify-apk.sh` searches for any `.apk` under the build outputs and **fails with a clear message if none exists**. It then checks (when the SDK tools are present): package id, versionName, not debuggable, permission deny-list, cloud backup off, size over 1 MB, and **APK signer SHA-256 equals the V5.0 identity**. It copies the APK to `dist/BeFyn_V6.5.apk`.
8. Uploads artifact **`BeFyn_V6.5-APK`** with `if-no-files-found: error`; always uploads `BeFyn_V6.5-build-logs`.

The Gradle task executed is `:app:assembleDebug`. The APK location is `android/app/build/outputs/apk/debug/app-debug.apk` (renamed in `dist/`). The APK is **not debuggable** (`debuggable false`) and signed with the V5.0 key; "debug" is only the Gradle variant name.
